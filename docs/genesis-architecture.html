System design  ·  Genesis

Four diagrams, one invariant: no credential ever reaches the browser.

Genesis turns a sentence into a working HighLevel app. That means three things run at once — an LLM streaming code, a sandboxed page executing that code, and a CRM holding somebody's real customer data. Nearly every architectural decision below exists to keep those three apart while still making the preview show live data.

01 — The map

What talks to what

Two Cloud Functions, one database, two outbound integrations. The browser never touches Firestore. Every read and write goes through a Cloud Function route that verifies the ID token, parses the payload with Zod and scopes the query by the uid it read off that token; the security rules deny every collection to every client, so a mistake in a route is a bug rather than a breach. This reverses the original design — the cost is onSnapshot, and liveness comes from refetching after a mutation or from the SSE stream that is already open.

02 — The decision that shapes everything

Why a proxy exists at all

The preview runs LLM-authored code in a sandboxed iframe. That code has to reach real HighLevel data or the whole demo is theatre — but the obvious way to do that would require putting an OAuth token where the page can read it. The proxy is the answer, and it's the one architecture decision worth spending the Loom minute on.

03 — The core loop

One generation, end to end

The product is this sequence. A prompt goes in, bounded context is assembled, Claude streams, and the same byte stream drives three things at once: text appearing in the editor, file boundaries opening and closing, and a snapshot written when it completes.

04 — The risky one

Getting a HighLevel token

Slice 2, day one. Because the app registers Target User = Sub-account, the install returns a Location token directly and the agency-to-location exchange never happens — one fewer moving part in the flow most likely to burn a day.

05 — Storage

Everything is a document

Files live in Firestore rather than Cloud Storage. They're small text blobs, and keeping them as documents makes snapshot-and-restore a copy operation instead of a bucket-manifest problem — which is most of feature F5 for free. Everything a user owns is nested under their uid, so the path is the ownership: there is no ownerUid field anywhere, and no equality check to forget.

users/{uid} — profile; email, displayName, timestamps projects/{projectId} — name, description, locationId, deletedAt files/{path} — the id IS the filename; content, size, timestamps messages/{messageId} — role, content, seq, truncated, error snapshots/{snapshotId} — seq, origin, fileCount, totalBytes files/{path} — the copy: path, content, size hlConnections/{uid} — tokens. Admin SDK only, never a client accessToken · refreshToken · expiresAt · locationId · locationName · needsReconnect authThrottle/{hash} — fixed-window counters, keyed by hash and never by address

Every rule is a denial, and every collection gets a test proving it — including for the owner, who reads and writes through the API like everybody else. That is what makes the rules a backstop rather than the enforcement: the route authenticates, parses with Zod and scopes by the uid on the token, and the rules are what turn a mistake in one of those routes into a bug rather than a breach. A snapshot's copies are a subcollection, because twenty files of up to 100 KB do not fit in one document — and rules do not cascade, so that subcollection is denied on a block of its own.

07 — When it breaks

Four failure modes, four visible behaviours

Spec section F8 is cross-cutting and mandatory. Each of these is an acceptance criterion with a test, not a nice-to-have.

What failsWhat the user sees
malformed LLM outputThe whole file set is refused and named — a bad path, a duplicate, an oversized file, an unterminated block. The reply is still stored, so the turn reads as a turn; the stored tree is byte-identical.
stream interruptedThe partial reply is persisted and marked Interrupted, and no file is written — a turn that did not complete describes an app whose remaining parts never arrived. Retry re-runs the stored turn, writing no second prompt.
HighLevel token expiredProxy refreshes silently. If refresh fails, the preview surfaces "reconnect HighLevel" rather than an empty list.
HighLevel API errorMapped to a readable message inside the preview — never a silent empty state that looks like real data.
